# smart-contract-balances — сверка остатков по госконтрактам (ГАУ ЦТО)

Считает сверку по госконтрактам заказчика **ГАУ ЦТО** из двух баз 1С:Fresh и публикует
**веб-отчёт**: по каждому контракту (и с раскрытием по заявкам) — **Заказано / Отгружено / Принято**
и два сальдо. Заказ №2 для СМАРТ ООО.

## Модель (три источника, два сальдо)

| Величина | Источник | База |
|---|---|---|
| **Заказано** | `Document_ЗаказПокупателя` | УНФ |
| **Отгружено** | `Document_РасходнаяНакладная` | УНФ |
| **Принято** | `Document_РеализацияТоваровУслуг` (УПД) | БУХ |

- Разрез: **контракт × заявка**. `Остаток к отгрузке = Заказано − Отгружено`,
  `Остаток к приёмке = Отгружено − Принято`.
- Ключ сшивки — номер госконтракта `ОК…/ЗК…` (парсится из текста; `regnum.mjs`). Охват — только
  контрагент ГАУ ЦТО (ИНН `9705101759`).
- Каждая величина суммируется внутри своей базы → сопоставление номенклатуры между базами не требуется.
- Только **чтение** из 1С (OData). Проверено на боевых базах: 18 контрактов, 59 заявок.

## Что на выходе

- **Веб-отчёт** `web/index.html` (+ `web/data.json`) — таблица по контрактам, клик по контракту
  раскрывает его заявки; переключатель шт/₽, поиск, итоги, минус-остатки красным.
- Публикуется на **GitHub Pages** через `.github/workflows/pages.yml` (по расписанию, данные свежие).
- Дополнительно `scripts/reconcile3.mjs` пишет CSV (`out/otchet_gau_cto*.csv`) — те же данные для Excel.

## Запуск

```bash
# локально: положить config.local.json (см. config.sample.json) с read-only кредами 1С
node scripts/build-web.mjs        # → web/data.json
python3 -m http.server -d web     # открыть http://localhost:8000
node --test                       # тесты (zero-dep, node:test)
```

## GitHub Pages (боевой)

1. Репозиторий → **Settings → Secrets and variables → Actions** → добавить:
   `BUH_BASE, BUH_USER, BUH_PASS, BUH_ORG, UNF_BASE, UNF_USER, UNF_PASS, UNF_ORG` (значения из `config.local.json`).
2. **Settings → Pages → Source: GitHub Actions**.
3. Запустить workflow «Отчёт на GitHub Pages» (или дождаться cron). Страница обновляется автоматически.

## Безопасность

- Креды — только в `config.local.json` / GitHub Secrets, **никогда в git** (`.gitignore`).
- **Внимание:** бесплатный GitHub Pages — **публичный**. В отчёте есть суммы/остатки. Для приватности —
  приватные Pages (платный план) или разместить те же файлы `web/` в Bitrix24 (управляемый доступ).

## Про «отчёт внутри УНФ»

Проверено: на 1С:Fresh **арендатор не может грузить свои расширения/внешние отчёты** в базу (список
«Расширения» доступен только для просмотра). Готовый дизайн-регистр и инструкция сборки лежат в
`docs/` — расширение может загрузить **обслуживающая организация (провайдер 1С)**; тогда отчёт можно
перенести внутрь УНФ. По умолчанию поставка — веб-отчёт (этот репозиторий).
